# v0.7 Q6 regime-aware anomaly event protocol

Status: frozen before the runner, current-head baseline, or production change.

## User boundary

An agent needs one actionable representation of an event. A persistent level
shift that is already represented by a supported changepoint must not also
arrive as a long list of independent point anomalies. An isolated spike may be
an anomaly, but the ordinary return to the prior level is not a second event.
A human must retain the exact changepoint and be able to see whether detector
selection used supplied labels or synthetic injection evidence.

This iteration changes neither changepoint detection nor the detector contest
unless the frozen evidence shows that either is itself defective. It first
tests whether the public investigation and anomaly surfaces express detected
points as coherent events.

## Frozen corpus

Use seeds `9101` through `9104`, 120 hourly observations, deterministic
Gaussian innovations with standard deviation `0.35`, and these six families:

- a permanent upward level shift of `+12` at index 72;
- a permanent downward level shift of `-12` at index 72;
- an isolated upward spike of `+18` at index 72 followed by a normal rebound;
- an isolated downward spike of `-18` at index 72 followed by a normal rebound;
- two genuine opposite-direction spikes at indices 72 and 76, testing that
  event normalization does not erase a nearby real event; and
- stationary noise with no planted event.

The generator family, seed, planted event indices, and expected event count
are scorer-only. Production receives only timestamped observations and the
public hourly frequency. Each case runs the production
`gnomon_investigate_change` surface and the production anomaly surface twice:
once without labels and once with the planted anomaly timestamps supplied as
ordinary user labels. Level-shift and stationary cases have no anomaly labels.
Machine-local TSFM supply is disabled so the compared detector pool is exact.

## Event scoring

Raw detector points are retained. Event-level matching uses a fixed
plus-or-minus-one-step tolerance and one-to-one matching: at most one alert
can match each planted anomaly, and every additional alert is a false event.
Report raw alert count, matched events, false events, event precision, event
recall, and per-family results separately for investigation, unlabelled
anomaly detection, and labelled anomaly detection.

Additional exact scores are:

- the strongest changepoint index and classification for level-shift cases;
- raw anomaly points after an admitted level-shift changepoint;
- an alert at index 73 after an isolated event at index 72, recorded as a
  rebound duplicate even though it is within the event-matching tolerance;
- both indices 72 and 76 retained in the nearby-events family;
- selection basis exactly `synthetic_injection_macro_f1` without labels and
  exactly `label_f1` when labels are supplied; and
- support state, detector identity, and all raw artifact paths.

Missing or failed rows remain in every denominator. No alert is considered
automation-eligible merely because the macro support is supported; this
benchmark scores descriptive event quality and surface honesty.

## Promotion gates

A general production change is promoted only if the exact candidate:

- completes all 24 cases on all three surfaces with deterministic replay;
- preserves a supported regime-shift classification and strongest
  changepoint within one step of index 72 on every level-shift case that the
  baseline gets right;
- has event-level anomaly recall no lower than baseline on each surface and
  in each planted-anomaly family;
- improves pooled event-level precision on every affected surface;
- emits zero anomaly points after a supported permanent-shift changepoint when
  those points are explained by that admitted regime;
- emits zero rebound duplicate at index 73 after an isolated spike;
- preserves both genuine nearby events on every case where baseline detects
  both;
- exposes the correct labelled versus unlabelled selection basis on every
  anomaly-surface row;
- does not suppress an alert using benchmark family, seed, hidden planted
  index, future observation, or expected event count; and
- passes focused tests and the complete suite isolated from machine-local
  TSFM supply.

If current head does not reproduce a reported defect, retain that
non-reproduction and do not change production. If a defect appears only in
one surface, change only the shared or surface-specific boundary responsible
for it and keep the other surface as a regression control.
