# v0.8 V1 final evaluation protocol

Status: frozen before V1 exact-head evaluation.

## Candidate and claim boundary

The production candidate is commit `1f31ece`. Aggregate benchmark artifacts
and final reporting may be added after it; any production change creates a new
candidate and requires affected shards to be repeated. Benchmark case IDs,
families, labels, future observations, and scores never enter product behavior.

V1 decides whether the accumulated v0.8 work is safe and useful enough to
recommend for a future release. It does not authorize a version change, tag,
upload, merge, or broad superiority claim. E1 and D1 hosted utility remain
separate from engine-contract completeness.

## Crash-safe execution order

All runs are sequential (`jobs=1` where applicable), preserve row-level
artifacts, use existing resumability, and retain failures in denominators.
Locally hosted TSFM discovery is isolated with
`GNOMON_TSFM_SANDBOX_ROOT=/tmp/gnomon-empty-tsfm-root`; API orchestration is
not assigned GPU resources.

1. Run PropertyBench seed `2026083801`, 12 replicates, and the production
   selector seed `2026083802`, 40 cases per family. Together their primary
   rows provide at least 500 deterministic cases, with additional held-out
   seasonality, volatility, dependence, transition, spike/extreme, and
   short-history diagnostics. Require complete accounting, immutable inputs,
   zero future use, no silent fallback, and every existing benchmark safety
   gate. Accuracy and coverage failures remain visible by family.
2. Run the 12 digest-pinned naturalistic datasets at ten frozen prefix
   fractions: `.50,.55,.60,.65,.70,.75,.80,.83,.86,.89` (120 cases).
   Require completion, zero future use, finite reference scores, complete
   provenance, and no silent fallback. Selector promotion gates are reported
   separately and cannot be repaired from held-out labels.
3. Accumulate at least 24 fresh ContextBench/TemporalBench agent-boundary rows
   in shards of at most four through Evidence and DeepSeek via Engy, with
   bounded retries/timeouts and resumable receipts. Require typed-contract,
   immutable-primary, relationship, answer/abstention, leakage, topology,
   token, request, retry, latency, and failure accounting. If the frozen
   provider credential is absent, record the lane as not run; deterministic
   engine tests do not substitute for agent preservation or decision utility.
4. Run at least 12 fresh CiK cases only when its external harness and provider
   are available. Otherwise record the external-evaluation blocker without a
   CiK performance claim.
5. Only after available shards are green, run the full repository suite with
   the isolated TSFM root, build wheel and sdist, install the wheel in a clean
   environment, and smoke-test version, CLI, MCP discovery, publication
   round-trip verification, agent decision seals, calibration-lineage
   preservation, and protected automation boundaries.
6. Push the exact head, open or update a draft PR, and require all exact-head
   CI checks. Keep the PR draft while any required external lane is pending.

## Decision

A release can be recommended only if every available local/naturalistic,
package, and CI safety gate is green and the missing hosted lanes are stated
as residual evidence gaps. Broad agent-accuracy or forecast-superiority claims
require their respective hosted/naturalistic performance gates and cannot be
inferred from contract tests. A failed safety invariant requires a general
production fix and affected rerun; a failed quality gate retains the safe
feature boundary or explicit opt-in rather than tuning to labels.
