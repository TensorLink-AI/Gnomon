# Gnomon guides

Gnomon gives an agent forecasts it can verify: Ephemeris, TensorLink's hosted
forecasting API, or your own models, run against frozen point-in-time data, with
every result carrying its snapshot, execution ID and evaluation evidence. The
optional ledger keeps predictions and outcomes across tasks so an agent can check
what worked before, even when observations are revised.
