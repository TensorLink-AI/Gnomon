# Gnomon guides

Gnomon gives an agent a forecast it cannot fake: Ephemeris hosted models or your
own, run against frozen point-in-time data, with every result carrying its
snapshot, execution ID and evaluation evidence. The optional ledger keeps
forecasts, revised actuals and scores so later corrections never overwrite
earlier predictions.
