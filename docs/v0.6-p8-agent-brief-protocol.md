# V0.6 P8 compact agent preservation protocol

Status: frozen before the current-head agent probe on 2026-08-30.

## User hypothesis and audit finding

Gnomon's brief and context outcome already contain typed primary, scenario,
source, limitation, and authority fields. The remaining risk is the model
boundary: a structurally correct engine response is not useful if the agent's
final human-facing synthesis says the announced change altered numbers when
the immutable primary already reflects it.

Earlier current-branch work added deterministic projections and scoring for
`relationship_to_primary`. A retained one-case run at older commit `4b5ea42`
preserved `no_distinct_numeric_path`; that is historical evidence, not
validation of the current v0.6 head. P8 begins with a small matched current-head
probe before considering any product change.

Use the checked-in frozen corpus at

change. This is not the full matrix.

## Frozen gates

All four selected cases remain denominators.

- **Engine completeness:** the deterministic history baseline and contextual
  Gnomon execution complete for 4/4, publication parity is 100%, and temporal
  leakage is zero.
- **Relationship opportunity:** report, without requiring a count, how many
  current-head engine responses expose `no_distinct_numeric_path`. Do not alter
  cases or engine thresholds if the count is small or zero.
- **Agent preservation:** on every exposed relationship, the final response
  must preserve that the claimed structural change creates no defensibly
  distinct numeric path because the emitted immutable primary already lacks
  the claimed continuation. Typed preservation rate must be 100%.
- **Primary and authority:** canonical-primary projection and automation-limit
  projection/preservation are 100%; no final response says context rewrote the
  immutable primary or authorized automation.
- **Source and limitation:** expected validated source references, rejection
  evidence, scenario consequence, and interval limitations are preserved at
  100% on applicable rows.
- **Response usefulness:** every answered row gives the user a concrete
  forecast submission plus a concise explanation of context disposition;
  agent completion is 4/4 with no provider or harness failure.
- **Topology:** jobs=1, bounded timeouts/retries, complete usage accounting, and
  resumable identity are present in retained artifacts.

Engine-contract completeness and agent-language preservation are scored and
reported separately. Inspect all four actual final responses, not only summary
booleans.

## Change and stop rules

If all gates pass, complete P8 as a validated no-build: avoid adding another
brief wrapper that only duplicates already-preserved typed fields. If a final
response loses a typed relationship while the engine and deterministic
projection are complete, fix only the general agent-boundary instruction or
projection defect, add a contract test, and rerun the identical shard. If the
engine omits or misstates the relationship, treat it as an engine-contract
defect separately; do not prompt-tune around it. Do not optimize to case IDs,
families, oracle labels, or DeepSeek phrasing.
