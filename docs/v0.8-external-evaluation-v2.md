# v0.8 response to the 0.7.0 external evaluation

Status: implementation complete; local validation and exact-head CI complete;
hosted-agent validation remains unavailable without an Engy credential. The
pull request remains draft for that external-evidence gap, not for CI.

## Product decision

The report reinforces Gnomon's intended shape: a temporal reasoning and
decision-safety layer for agents, with forecasting models behind governed
evaluation rather than a replacement for every forecasting library. The
highest-value fixes are therefore the ones that prevent a wrong canonical
claim, preserve a useful bounded answer when probability support is absent,
and make the operational verbs reachable and repairable from an agent host.

The implementation consumes no benchmark identity, expected label, hidden
future, or fixture-specific value. Every behavior below is expressed in
terms of observable series structure, support state, task, and interface
contract.

## Decisions by finding

| Finding | Decision | User outcome |
| --- | --- | --- |
| Seasonal business growth described as constant | Fixed | `describe trend` residualizes admitted seasonal phases and persistent regimes before testing slope, so the canonical human/agent answer no longer treats seasonality as unexplained noise. |
| Exactly two hourly cycles select 23 or report zero strength | Fixed narrowly | The upper ACF boundary is eligible only when it equals the frequency prior. All 24 phase offsets of a clean 48-point hourly cycle select period 24; mature-series selection is unchanged. |
| MCP hides operational verbs | Fixed | The default core surface exposes the nine user verbs (inspect, describe, forecast, investigate, detect, decide, monitor, and route, plus capabilities) and run explanation. Administrative and state-mutating tools remain profiled. |
| Cold-start `route` returns no recommendation or exclusions | Fixed | It returns a disclosed structural starting candidate, states that backtesting remains required, and explains structurally ineligible candidates. It never promotes the starting point into a forecast. |
| Long degraded threshold answer is a flat primary | Fixed at the decision boundary | A materially longer, single-series, context-free threshold request publishes its evaluated prefix followed by a continuous, labelled best-effort tail. The canonical bounded answer is `indeterminate` when the primary and a labelled alternative disagree; the nested primary remains inspectable. |
| Generic flat degraded forecast | Retained for now | Automatic prefix splitting without a threshold changed unconditional output when context was added and made wide responses expensive. The broader behavior was rejected rather than shipping that agent-invariance defect. The existing model-assisted lane remains visible. |
| `--candidates` rejects comma lists | Fixed | Repeated and comma-separated candidate arguments are flattened and deduplicated consistently. |
| Prometheus `.yaml` contains JSON | Fixed | The generated rule is dependency-free block YAML with quoted scalars. |
| `investigate` has no headline | Fixed | It names no-change, a single classified change, or a multi-series count without asserting causality. |
| Frequency help omits general minute steps | Fixed | Typed details name `<N>s`, `<N>min`, and `<N>h` as supported patterns. |
| Month-start repair offered for intraday data | Fixed | That repair is offered only when every observation is actually month-end shaped. |
| Empty error details referenced by repair | Fixed for frequency failures touched here | Short, regular-unrepresentable, and irregular frequency failures now carry observations, supported patterns, observed spacing, and/or regularity as applicable. |

The earlier 0.7 intake remains historical evidence and is not rewritten.

  `upward`, slope `2.3873302602` per step, standard error `0.1239567627`,

  zero internal errors.

  claim and does not enable StatsForecast by default.

  wheel and source distribution build, and the wheel passes a clean Python
  3.12 inline-observation/MCP/trend smoke.
