# Graduated-horizon publication protocol

Status: protocol v2 treatment rejected; protocol v3 follows below.

The first reference audit found that applying an hourly daily-season floor to
only 48 points leaves no separated prefix to evaluate: two complete daily
cycles consume the entire history. Treating that case as splittable would
weaken the evidence contract. Before any production treatment, v2 therefore
uses daily grids for the non-seasonal families and retains the hourly seasonal
family as a no-op control. The rejected v1 reference remains retained as loop
132.

This protocol tests a general product question: when a full requested horizon
earns only a flat degraded last-value forecast, but the same history supports a
shorter separated evaluation, should Gnomon publish that evaluated prefix and
label only the remaining rows as best effort?

The frozen matrix contains 20 unseen seeds from each of four families: daily
trend, hourly seasonal, daily stable level, and daily random walk. Every case
has 48 visible observations and a 24-step requested horizon. The seasonal
family declares a 24-step period and acts as a no-op control when it already
publishes a non-flat seasonal path. Future targets are generated with the case but are never
written to Gnomon's input or passed to its forecaster; they are opened only
after publication for WIS and absolute-error scoring.

Reference eligibility is structural, not outcome-selected: a reference case
must publish a degraded, flat, last-value path with no existing horizon split.
The treatment must use the ordinary production stages at the supportable
shorter horizon. It may not use the hidden future, loosen model admission, or
promote the best-effort tail.

Promotion requires all of the following:

- at least 80% of structurally eligible cases receive a contiguous evaluated
  prefix and best-effort tail;
- every split advertises `tier_floor: best_effort`;
- aggregate WIS does not regress and aggregate MAE improves by at least 2%;
- combined trend/seasonal WIS improves by at least 10%;
- combined stable-level/random-walk WIS regresses by no more than 2%;
- no family's median WIS regresses by more than 3%;
- all horizons are complete, all quantiles are finite and ordered, and no
  future target reaches the forecaster.

These gates reward a useful graduated answer while retaining the product's
core rule: unavailable evidence can reduce authority, never manufacture it.

## v2 outcome and v3 correction

The v2 treatment improved signal-family WIS by 29.5%, aggregate WIS by 16.4%,
and aggregate MAE by 10.6%, but failed its safety controls: stable-level WIS
regressed 47.6% and random-walk WIS regressed 4.2%. In those cases the shorter
evaluation selected the same last-value point path; replacing only its
uncertainty added no forecast information and was harmful. The treatment was
therefore rejected.

Protocol v3 freezes a stricter, label-free eligibility condition before the
next treatment. The reference runner requests the supportable shorter horizon
using the same visible history and production stages. An ordinary forecast is
eligible for a graduated split only when that shadow prefix has a point path
materially distinct from the flat full-horizon primary. Cases whose prefix is
not distinct become byte-preservation controls. Hidden futures remain excluded
from both decisions.

Promotion under v3 requires every distinct-prefix case to split, every
no-distinct-path control to retain its original numeric rows, aggregate WIS to
not regress, distinct-prefix WIS to improve by at least 10%, safety-control WIS
to regress by no more than 2%, and every original completion, ordering, tier,
and future-isolation gate to pass.
