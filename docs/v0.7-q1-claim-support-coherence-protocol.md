# v0.7 Q1 forecast claim/support coherence protocol

Status: frozen before the current-head reproduction and production change.

## Diagnosed boundary

The external-evaluation intake asks whether a protocol-complete forecast can
emit high-confidence prose at zero or immaterial measured gain, and whether a
degraded long-horizon fallback can expose actionable threshold probability.
These are interface-contract questions, separate from model selection skill.

The current deterministic headline template has a suspicious branch: any
`supported` result with a numeric `baseline_improvement` says the selected
model beat the strongest baseline, including when the published model is that
baseline and improvement is exactly zero. Structured evidence can therefore
be numerically correct while the sentence an agent is explicitly allowed to
relay verbatim overstates what was demonstrated.

## Frozen reproduction corpus

Use production `forecast()` with machine-local TSFM discovery isolated. Every
case is deterministic, receives only its visible history, and is inspected in
the persisted artifact, `summary.md`, full tool summary, and brief tool
summary:

1. `stationary_level_seed_123`: 120 daily observations generated as
   `50 + Normal(0, 5)` with Python `random.Random(123)`, horizon 7. This is the
   baseline-retention case; no particular winner is hard-coded into a future
   production rule.
2. `linear_trend`: 120 daily observations generated as `20 + 0.8 * index`,
   horizon 7. This is the positive-uplift control.
3. `short_noisy`: 18 daily observations generated as
   `50 + Normal(0, 5)` with seed 321, horizon 3. This is the degraded/support
   control.
4. `long_horizon_threshold`: 30 daily observations generated as
   `40 + 0.2 * index + Normal(0, 1)` with seed 456, horizon 12 and threshold
   50. This probes split or sub-supported rows and threshold availability.

The generator label, seed, expected semantic role, and any later outcomes are
benchmark metadata only and never reach `forecast()`.

## Frozen measurements

For every case retain:

- selected model, strongest baseline, measured improvement, support status,
  row tiers, interval coverage, and threshold payload;
- artifact headline and the first non-empty line of `summary.md`;
- full and brief tool-summary headlines and their support/threshold fields;
- whether the headline claims `beat`, `high-confidence`, `baseline retained`,
  `no measured uplift`, caveats, naive extrapolation, or probability;
- exact agreement among all four headline surfaces; and
- typed reasons, disclosures, warnings, and recovery actions.

Engine support and product publication remain separate. This benchmark scores
the consistency of claims with already-measured evidence; it does not score
forecast accuracy and cannot authorize a model-selection change.

## Reproduction and promotion gates

The current-head reproduction passes only when:

- all four product cases complete and all four surfaces are captured;
- all four headline surfaces agree exactly within each case;
- a baseline-selected result with zero improvement does not claim that a
  model beat the baseline and does not call that comparison high-confidence;
- a non-baseline supported result with positive measured improvement may name
  the measured uplift, but only when the structured model identity and value
  agree;
- conditionally-supported, degraded, split, or best-effort output never uses
  an unqualified high-confidence headline;
- any unavailable or non-verifiable threshold probability is absent or typed
  unavailable consistently in artifact, full, and brief surfaces;
- a split horizon names the evaluated prefix and naive remainder; and
- no support, automation authority, model identity, probability, or numeric
  forecast is changed by headline rendering.

Expected baseline failures are evidence for a general rendering fix, not
permission to special-case these seeds, model names, or labels. Promotion
requires a matched rerun on the exact implementation commit, focused support,
threshold, artifact, CLI/tool, and golden tests, followed by the full isolated
suite.
