# v0.8 loop I001: economical and resilient orchestration

Status: protocol frozen; fresh baseline pending.

The topology audit found that compiled, host-bound Evidence cases still pay a
model turn to repeat a deterministic tool choice before the final synthesis
turn. Repair-only submissions add further cost when exact engine-authored
response obligations are scattered across the publication. The frozen
candidate combines a compact engine-authored response contract with a
fail-closed host-preexecution path for fully typed and bound requests.

Development and untouched confirmation corpora were generated before the
change. Full hashes, arms, metrics, retry policy, gates, and kill criteria are
in `docs/v0.8-e1-orchestration-protocol.md`.
